Signing requirement:
The AAB uploaded as an update must be signed with the upload key accepted by the existing Google Play app. That private keystore was not present in the files available to this build environment and should not be placed in the source ZIP. Use the same keystore/key alias used to sign versionCode 1 on the Windows PC. If it is lost, use Google Play's upload-key reset process rather than generating an unrelated key and expecting Play to accept it.

Build on Windows / Android Studio:
1. Deploy the matching V18.8.45 web source first (or at the same time), because the Android shell loads https://ispeakconfidence.com.
2. Open the android-app folder in Android Studio.
3. Sync Gradle and install SDK 36 if Android Studio asks.
4. Build > Generate Signed App Bundle / APK > Android App Bundle.
5. Select the EXISTING iSpeak upload keystore and key alias.
6. Build release.
7. Upload the resulting app-release.aab to the existing Closed testing track.
