iSpeak Confidence V16.1.3 — Library Full QA & Bugfix Pass

Library bugs found and fixed:
1. French/Spanish/Mandarin/Japanese/Arabic/Khmer displayed an obsolete message saying books had not been bundled. Fixed.
2. Khmer's “Intermediate / Advanced” book could disappear when filtering Intermediate or Advanced because the filter required an exact level string. Fixed.
3. File-backed books could show incorrect shelf progress before their page total was known. Page totals are now persisted after first load and progress is calculated safely.
4. Bookmarking stored only a true/false flag, not the bookmarked page. It now stores the exact bookmark page and “Go to bookmark” works.
5. On mobile the reader displayed one page but Next/Previous moved two pages, causing every second page to be skipped. Fixed: mobile moves one page; desktop spread moves two.
6. Closing the reader using the generic modal close path could leave reader-dialog styling attached to later modals. Fixed.
7. Added empty/unreadable book guard.
8. The six file-backed multilingual books were not actually in the service worker CORE pre-cache despite earlier release notes. Fixed: all six are now explicitly pre-cached for offline reading after the PWA is installed/loaded.
9. Bookmark footer now accurately displays Bookmarked state.
10. The misleading Contents button was changed to Current chapter / Go to bookmark because this reader does not yet have parsed chapter navigation.
