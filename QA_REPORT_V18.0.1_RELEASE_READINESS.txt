Fixes made during this release-readiness pass:
1. Removed admin PIN support from URL query parameters for private qualification files.
2. Strengthened uploaded image/video/PDF validation so signature-only fake files are rejected.
3. Upload file extensions now come from verified MIME type rather than applicant-supplied filename.
4. Improved service-worker offline fallback so missing images/scripts are not replaced with index.html and failed HTTP responses are not cached.
5. Added missing accessible labels to close controls.
6. Updated Privacy Policy and Terms for teacher application/profile data and teacher conduct.
7. Corrected remaining V18.0.0 release/version labels and package metadata to V18.0.1.

Known intentional exclusions:
- Gemini/AI evaluation, transcription, AI chat and AI TTS were not tested because no AI key is configured.
- SMTP/email sending was not tested because email credentials are not configured.

Important production requirements (configuration, not code failures):
- Set DATA_DIR to persistent storage or migrate to a production database before accepting real users at scale.
- Set strong ADMIN_PORTAL_PIN and TEACHER_PORTAL_PIN values in production.
- Deploy behind HTTPS.
- Configure AI/email only when ready.

Note: Browser automation could not be executed in this QA environment because the installed browser is administrator-blocked from navigation. Functional HTTP/API integration, static structure, media validation and source-level checks were used instead. A final real-device/browser smoke test on Windows Chrome plus at least one Android/iOS device is still recommended before public release.
