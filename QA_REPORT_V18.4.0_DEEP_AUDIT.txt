TRANSLATION LIMITATION (INTENTIONAL, NOT SILENTLY FABRICATED)
The international support-translation layer does not yet contain human-verified translations for
every source/target language pair. Where a verified translation is unavailable, the app uses the
explicit English fallback. In particular, this audit did not invent Khmer learner-facing text. Full
human localization of every support string in every language remains a separate content/localization
workstream if complete native-language coverage is required.

EXTERNAL-SERVICE ITEMS THAT REQUIRE REAL PRODUCTION CREDENTIALS/INFRASTRUCTURE
- Gemini-backed AI functions require GEMINI_API_KEY.
- Direct server email/certificate delivery requires valid SMTP settings.
- Production-grade WebRTC reliability on restrictive networks requires a working TURN service.
These integrations cannot be fully proven without the real configured third-party services.
