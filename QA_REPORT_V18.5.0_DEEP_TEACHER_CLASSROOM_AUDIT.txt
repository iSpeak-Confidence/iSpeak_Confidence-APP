CHANGES VERIFIED
1. Google-Meet-style background effects
   - Uses pinned MediaPipe Selfie Segmentation in the browser when available.
   - Person mask is composited over blur, iSpeak Light Studio or iSpeak Dark Studio backgrounds.
   - Basic fallback remains if the segmentation model cannot load.
   - Preview-effect resources are explicitly stopped when switching effects, leaving pre-join, or entering class.

2. Classroom lesson files replace shared classroom chat UI
   - PDF and Word .docx sharing, maximum 12 MB.
   - Files are scoped to the exact classroom booking.
   - PDF can be previewed inside the classroom.
   - DOCX content gets a protected in-class text preview while the original remains downloadable.
   - DOCX is structurally checked for real Office package entries, not only a .docx extension/ZIP header.
   - Unrelated students are blocked from both original files and previews.

3. Conversation-only classroom mode
   - Teacher/student can hide lesson tools and concentrate on the two video tiles.
   - Fullscreen uses the browser Fullscreen API with a CSS full-viewport fallback.
   - Fullscreen fallback can now be exited reliably; Escape/fullscreen state updates are handled.

4. Teacher profile
   - Reworked into iSpeak navy/teal portal layout.
   - Public-profile preview, editable teaching headline/about/specialties, photo and intro-video sections.
   - Public profile changes remain admin-reviewed.

5. Teacher Academy
   - 8 substantial modules with 16 checkpoint questions total.
   - Final: 10 applied questions + 50-minute lesson-plan assignment.
   - Minimum 80% final knowledge score.
   - Lesson plan requires 650+ characters and at least 8/10 rubric areas.
   - Professional certificate preview is visible before completion.
   - Passing certificate contains the logged-in teacher's name, date and unique certificate ID.
   - Certificate can be downloaded as vector SVG or printed/saved as PDF.

6. Student course certificate
   - Course-completion certificate has a direct download control.
   - Learner name, course, date and certificate ID are included.
   - Print / Save as PDF and email options remain.

LIMITS OF THIS AUDIT
No automated environment can honestly prove a browser/video application is "100% bug free" on every physical phone, laptop, camera, microphone, browser, network and NAT configuration. This audit therefore combines code/syntax checks, the existing 68-test suite, targeted server/API tests and static feature checks. Physical webcam/microphone permissions, real two-device WebRTC media quality, and the MediaPipe person mask still need a final real-device check in Chrome/Edge. TURN credentials are also required for reliable WebRTC across difficult networks in production.
