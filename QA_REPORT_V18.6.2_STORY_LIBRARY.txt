Browser-environment note:
The container Chromium policy returns net::ERR_BLOCKED_BY_ADMINISTRATOR for localhost, so an automated visual Chromium click-through cannot be truthfully marked PASS in this environment. The original failure was identified as a CSP conflict: the production CSP disallows inline event handlers, while V18.6.1 generated inline onclick controls. V18.6.2 removes those inline handlers entirely and uses external app.js event listeners, which matches the active CSP.
