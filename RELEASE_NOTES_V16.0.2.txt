iSpeak Confidence V16.0.2 — Learning Engine / Release Hardening

FIXED IN THIS BUILD
- Writing Academy character-card selector bug fixed.
- Narrow characters are judged by meaningful stroke distance/size rather than requiring a wide drawing.
- Character mastery advances automatically and does not loop back after the final character.
- Unit learning blocks are sequentially locked; learners cannot jump directly to Mastery.
- Placement difficulty-band pass threshold raised to 75%.
- Placement uses 30 different curriculum targets and removes answer choices after the opening section.
- Question/statement distractor matching retained to reduce giveaway answers.
- PWA service-worker registration moved out of inline HTML so the production CSP does not block it.
- Offline cache bumped to V16.0.2.
- Version identifiers updated across server, package, UI and launcher.
- Stale backup/old release-note files removed from the release package.

KHMER AUDIO
- 121 validated human Common Voice clips are bundled for Native Listening.
- Exact-match policy remains enforced for normal Khmer lesson audio.
- Current 60 core Khmer targets have no exact match in the bundled 121-clip set, so those lesson buttons correctly report that verified audio is unavailable rather than playing a wrong/synthetic clip.

KNOWN RELEASE LIMITS
- Curriculum breadth still needs expansion before claiming a long B2-equivalent course.
- Drawing checks effort/coverage, not true stroke order or glyph recognition.
- Browser speech recognition is not a full pronunciation scorer.
- Production SMTP/Gemini credentials and real-device/browser QA must be tested in the deployment environment.
