iSpeak Confidence V18.1.0 — Full Teacher Portal

- Upgraded teacher applications into a complete teacher lifecycle.
- Approved teachers use their own application email/password for portal access.
- Added teacher dashboard overview with upcoming lessons, student count, completed lessons and pending earnings.
- Added live weekly availability management with teacher timezone.
- Added full lesson manager: confirm/cancel/complete, Google Meet or Zoom link, and private lesson notes.
- Added student roster generated from real bookings.
- Added earnings ledger for completed classes with pending/paid status.
- Added editable approved public profile headline, bio and specialties.
- Added teacher application declarations for 18+, equipment, reliable internet and teacher rules.
- Added admin controls for approval, teacher pay rate, profile active/paused state, manual identity verification and payment status.
- Approved teachers can be hidden from bookings without deleting their accounts.
- Retained legacy PIN portal for manually-created teachers as a fallback only.

Security note: identity status is tracked, but the app deliberately does not store passport/government-ID uploads in the ordinary application upload folder.
