iSpeak Confidence V18.2.0 — Professional Teacher Accounts

- Admin can create individual accounts for existing teachers with temporary passwords.
- Existing teachers are forced to create their own password on first login.
- Teachers can change their password later from the portal.
- Teachers can edit bio, headline, specialties, profile photo and intro video.
- Public profile edits enter an admin-review queue and do not go live before approval.
- Availability remains teacher-controlled and publishes immediately.
- Admin can approve or reject profile edits.
- Existing booking, lesson, student and earnings functions remain integrated.
- Teacher portal upload request limit now matches the supported intro-video size.
