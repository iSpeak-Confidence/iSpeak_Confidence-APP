iSpeak Confidence V18.3.0 — iSpeak Classroom
13 August 2026

NEW CLASSROOM
- Authenticated classroom tied to each real booking.
- Teacher joins from Teacher Portal lesson manager.
- Student joins from My Lessons using the matching learner account.
- Browser WebRTC video/audio with camera, microphone and screen-share controls.
- STUN fallback and optional TURN_URL / TURN_USERNAME / TURN_CREDENTIAL production relay configuration.
- Persistent in-class chat and shared lesson workspace.
- Attendance/join tracking for teacher and student.

QUALITY & SAFEGUARDING
- Classroom entry explicitly discloses possible live quality monitoring and recording.
- Teacher and student must acknowledge the classroom notice before entering.
- Admin has authenticated read-only observer mode; admin sends no camera or microphone into the class and no admin tile is added to the participant grid.
- Teacher browser creates segmented classroom recordings after both teacher and student acknowledgements are present.
- Recording uploads are authenticated, size-limited and validated as supported video files.
- Replays are outside the public static tree and require admin authentication.
- Privacy Policy and Terms updated for classroom monitoring, recordings and reviews.

REVIEWS
- Student can review only an attended, completed iSpeak Classroom lesson.
- Exactly one review per booking.
- 1–5 rating plus written feedback.
- Verified reviews feed the teacher profile rating and public review list.
- Admin backend supports hiding/restoring a review if moderation is required.

RELIABILITY / SECURITY
- Fixed explicit teacher Authorization header being overwritten by an existing learner login token.
- Classroom polling has a dedicated rate-limit budget suitable for long lessons.
- WebRTC ICE candidate buffering added for candidates that arrive before the remote description.
- Failed peer connections can be recreated on subsequent presence polls.
- Recording chunks use reduced bandwidth and 30-second independent segments to lower data-loss risk and storage load.
- Persistent production storage should be configured through DATA_DIR.

QA
- V18.3.0 automated QA: 35/35 passed.
- End-to-end real server test passed for teacher account, student account, booking, classroom authentication, attendance, collaboration, signaling transport, admin observer, valid recording upload, protected replay, lesson completion, verified review, duplicate-review rejection and public rating aggregation.
