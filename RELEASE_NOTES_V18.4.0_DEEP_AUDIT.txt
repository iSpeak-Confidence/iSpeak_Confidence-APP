iSpeak Confidence V18.4.0 — Deep Audit Release Notes
====================================================
Date: 13 August 2026

This release is a whole-app hardening pass over V18.3.0. It intentionally prioritizes
reliability, release consistency, privacy/security hygiene and content integrity rather than
adding another large product area.

FIXES COMPLETED
1. Offline/PWA integrity
   - Replaced the stale V17.3 manual cache namespace with the V18.4.0 cache.
   - Added missing core dependencies to offline caching, including ielts-data.js,
     curriculum-expansion-v17-4.js and language-support-v17-5.js.
   - Aligned the manual cache and service-worker core dependency lists.

2. Teacher authentication cleanup
   - Removed the retired shared teacher PIN UI, API route, helper and environment setting.
   - Existing and newly approved teachers use individual email/password accounts.
   - The forced temporary-password replacement flow remains intact for provisioned teachers.

3. Release/version consistency
   - Updated page title and visible What's New content to V18.4.0.
   - Synchronized package.json and package-lock.json name/version metadata.
   - Updated the Windows startup launcher to start-v18-4-0.bat.
   - Replaced stale README instructions with V18.4.0 instructions.

4. Library integrity
   - Audited every processed library book/chapter/page.
   - Removed no book text and invented no replacement text.
   - Merged only obvious tiny pagination fragments such as running headers, page numbers,
     isolated captions and split half-lines into adjacent pages.
   - Preserved one genuinely short chapter page where the short text is the actual content.
   - Confirmed library metadata chapter counts match processed chapter counts.

5. Translation/content integrity
   - Corrected an Arabic punctuation error (Arabic question mark).
   - Audited support-language coverage and preserved explicit English fallback where a verified
     translation is unavailable.
   - Did not fabricate missing Khmer learner-facing translations or curriculum text.

6. Accessibility/static UI hygiene
   - Added accessible labels for library search, library sort and conversation-message input.
   - Audited local runtime references and verified referenced local assets/books exist.

7. QA expansion
   - Expanded the release suite from 35 checks to 55 checks.
   - New checks cover release metadata, offline dependency completeness, retired auth paths,
     Arabic punctuation, accessibility labels, local reference integrity, 30-unit curriculum
     integrity, exact anchor repetition, processed-library page integrity, and chapter metadata.

CLASSROOM / ACCOUNT REGRESSION TEST
A clean-server end-to-end test passed through:
admin provisioned teacher -> temporary teacher login -> forced password change -> availability ->
student registration -> booking -> student classroom entry -> teacher classroom entry -> attendance ->
chat/signaling -> read-only admin observer -> completed lesson -> verified review -> duplicate review
rejection -> validated WebM recording upload -> learner replay rejection -> authenticated admin replay ->
review published on teacher profile -> retired shared-teacher-PIN endpoint remains unavailable.

See QA_REPORT_V18.4.0_DEEP_AUDIT.txt for the final verification matrix and remaining production
configuration items.
