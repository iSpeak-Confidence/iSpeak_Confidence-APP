iSpeak Confidence V18.5.0 — Tutor Pricing, Teacher Calendar & Booking-Room Sync

Changes
- Removed the fixed $6 trial price from the public teacher page and booking buttons.
- Removed the separate lesson-pricing box; the teacher page now keeps one New Learner Offer box.
- Welcome offer is 30% off the learner's first TRIAL lesson with any tutor using WELCOMETOISPEAKCONFIDENCE.
- Tutor lesson rates are teacher-set with a hard $10/hour minimum enforced on both client and server.
- Trial lessons use the tutor's published lesson rate; teachers receive 75% of the full listed trial value, so the welcome discount is funded by iSpeak.
- Teachers without a published rate cannot accept a paid booking until they set a rate.
- Added Teacher Portal > Pricing.
- Added Teacher Portal > Calendar with monthly bookings and direct classroom entry.
- Added Teacher Portal > Virtual Classroom listing only that teacher's booked rooms.
- Student booking now requires a logged-in student account and the booking email must match that account.
- Each classroom is keyed to the unique booking ID. Teacher access is bound to the approved teacher application/account ID where available, and student access is bound to the booked student account email.
- Wrong students and wrong teachers are denied access to another booking's classroom.
- Existing student My Schedule and Virtual Classroom continue to use the same booking IDs, so both sides open the exact same room for the exact same lesson.
- Service-worker cache version bumped so browsers receive the new UI.

Verification
- Existing automated V18.5.0 QA: 68 passed, 0 failed.
- Functional API test: $10 minimum enforced; $12 tutor rate published; 30% trial promo produced $8.40 student total; teacher trial earning remained $9.00 (75% of $12); unauthenticated booking rejected; booking appeared in both student and teacher booking feeds; teacher and correct student opened the same booking classroom; second student denied; second teacher denied.
