iSpeak Confidence V18.8.14 — Email Authentication Reliability Fix

Fixed for BOTH student and teacher accounts:
- New-device verification now waits for SMTP delivery to succeed before showing the 6-digit-code screen.
- If email delivery fails, login now returns a clear error instead of falsely saying a verification code was sent.
- Password-reset email configuration now reports a clear Render environment setup error.
- SMTP password supports SMTP_APP_PASSWORD (recommended) and SMTP_PASSWORD alias.
- /api/status reports whether account email is configured and which SMTP host/port are selected.
- Startup log now reports Account & Certificate Email READY/OFF.

Required Render environment variables for Gmail SMTP:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=<your Gmail address>
SMTP_APP_PASSWORD=<Google App Password, not your normal Gmail password>
CERT_FROM_NAME=iSpeak Confidence

No teacher/student roles, admin permissions, bookings, learning content, or unrelated app behavior were intentionally changed.
